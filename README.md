# Государственный архив Восточно-Казахстанской области — новый сайт

Прототип для хакатона Code Masters 9.0 по техническому заданию заказчика и дополнениям от 10.11.2026.

**Демо-стенд:** https://gosarhiv-vko.vercel.app · админка `/admin` (учётные данные передаются комиссии отдельно).

Сайт **информационно-справочный**: здесь нет форм заявлений, заказов, оплаты и приёма обращений. Подать запрос на архивную справку можно на [eGov.kz](https://egov.kz) или через [e-Otinish](https://eotinish.kz), и сайт явно ведёт туда.

## Запуск на своём компьютере

Нужен Node.js 20.10 или новее. Базу данных ставить не нужно: без настроек используется встроенный PostgreSQL (PGlite) в папке `.data/`.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте http://localhost:3000. Перед запуском команда `npm run dev` сама создаёт таблицы и заполняет начальные данные: роли, тестовых сотрудников, архив и филиалы.

### С PostgreSQL в Docker

```bash
docker compose up --build
```

Поднимаются PostgreSQL 16 и сайт на http://localhost:3000.

### С внешним PostgreSQL (Supabase и др.)

Укажите `DATABASE_URL` в `.env.local` и выполните `npm run db:setup`.

## Тестовые учётные записи

Админка — `/admin`. Логины: `admin`, `siteadmin`, `editor`, `archivist`, `ridder` (администратор Риддерского филиала), `moderator`, `analyst`. Пароль задаётся в `DEMO_PASSWORD`. Учётные данные публичного демо-стенда передаются комиссии отдельно.

## Архитектура

| Слой | Решение | Почему |
|---|---|---|
| Сайт и админка | Next.js 15 (React, TypeScript), серверная отрисовка; админка `/admin` на серверных действиях с проверкой прав в каждом действии | ТЗ 6, 7.3, 7.6 |
| База | PostgreSQL 16; локально — PGlite (тот же PostgreSQL в WebAssembly) | ТЗ 7.6; запуск без установки |
| Поиск | Полнотекстовый поиск PostgreSQL (русская морфология) + `pg_trgm` для вариантов написания | Аналог Elasticsearch, который допускает ТЗ 7.6; для 20–50 тысяч записей отдельный поисковый сервер не нужен. В индекс попадают только опубликованные открытые записи (доп. ТЗ 3.1) |
| Файлы | Объектное хранилище, совместимое с S3 (Supabase Storage / MinIO) | ТЗ 7.7: мастер-копии, облегчённые копии, контрольная сумма |
| ИИ-помощник «Ахмет» | Языковая модель через API (OpenRouter — DeepSeek, или Anthropic — выбирается настройкой) с инструментом поиска по открытому каталогу; без ключа — ответы по шаблону с пометкой «демо». Внешние сервисы — [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md) | ТЗ 5.8, доп. ТЗ 3.4, 3.6 |
| Голосовой ввод | Распознавание речи браузера (Web Speech API) | Без внешних сервисов и ключей |
| Карта | OpenStreetMap; маршрут — переход в 2GIS / Google Maps | ТЗ 5.5; работает и без геолокации |

Структура папок:

```
db/migrations/   SQL-схема (фонд → опись → дело → документ, файлы, роли, согласование, журнал)
db/seed/         начальные данные с указанием источника
scripts/setup.ts миграции и начальные данные
src/app/[lang]/  страницы на трёх языках: /kk, /ru, /en
src/components/  шапка, подвал, переключатели языка и темы, помощник «Ахмет»
src/i18n/        тексты интерфейса
src/lib/db.ts    доступ к базе, только параметризованные запросы
src/lib/catalog.ts поиск и все правила доступа к записям и файлам каталога
src/app/api/     /api/catalog — поиск; /api/files/<id> — копии с проверкой прав
docs/            готовность модулей, ограничения
```

## Источники данных

- Контакты, часы работы, адреса филиалов: материалы заказчика (`Контакты.docx`, `Адреса и контакты филиалов.xls`).
- «Об архиве»: «История архива.docx», «Структура.docx», материалы комплаенс-службы (тексты и PDF) — `scripts/convert/pages_from_docx.py` → `db/seed/data/pages.json`; читальный зал и законодательство — `db/seed/pages.ts` с указанием источников.
- Хронология летописи: «Календари юбилейных и памятных дат ВКО» 2022–2026 (материалы заказчика). Перенос — `scripts/convert/calendar_from_docx.py` → `db/seed/data/chronicle-events.json`.
- Фонды: перечни «Фонды госархива ВКО» и «Партийные фонды» (2018), опубликованные на e-arhiv.vko.gov.kz; ссылки на них даны в материалах заказчика (`Фонды.docx`). Перенос — `scripts/convert/funds_from_xlsb.py` → `db/seed/data/funds-2018.json`. Фонды с названием «секретный фонд» загружаются со статусом «Не публиковать».
- Логотип и фото здания: прежний сайт e-arhiv.vko.gov.kz (копия в веб-архиве).
- Координаты филиалов не заданы: их подтверждает архив (доп. ТЗ 3.3).
- Демонстрационные записи каталога, новости и изображения помечены как «демо».

Готовность модулей — в [docs/READINESS.md](docs/READINESS.md), внешние сервисы — в [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md), выкладка стенда — в [docs/DEPLOY.md](docs/DEPLOY.md).
