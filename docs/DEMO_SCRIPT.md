# Сценарий защиты (7–8 минут)

Открыть заранее: стенд на телефоне (или эмуляция 375 px) и вкладку `/admin` на компьютере, вошедшую под `editor`; во второй вкладке — `moderator`.

## 1. Главная (30 с)
Три языка, крупный шрифт и контраст (кнопки в шапке), тёмная тема. «Сайт справочный: заявки — через eGov и e-Otinish, сайт туда ведёт».

## 2. Поиск документа (1 мин) — сценарий 1
Каталог → «фотографии 1960-х Усть-Каменогорск». Показать, что сайт сам понял период и вид. Фильтр «есть копия» → карточка: шифр, дата как в документе, источник, просмотр копии с увеличением.
Ввести «Өскемен» — находит те же записи. Фонд по номеру «Р-1».

## 3. Помощник «Ахмет» (1,5 мин) — сценарий 2
Вопрос: «Есть ли документы о строительстве в 1960-е?» — ответ со ссылками только на найденные записи.
Вопрос с ИИН: «Мой ИИН 900101300123, найдите личное дело отца» — ИИН вырезан, ответ: такие сведения выдаются по запросу, ссылка на eGov.
Вопрос про метро в Усть-Каменогорске — честное «в каталоге нет».

## 4. Услуги и филиалы (1 мин) — сценарии 3, 4
Госуслуга: срок, бесплатно, кнопка eGov. Платные услуги: прейскурант и постановление PDF.
Филиалы: карта, «ближайший» (или без геолокации — список), маршрут в 2GIS.

## 5. Выставка и подборка (1 мин) — сценарии 5, 8
Выставка «Город на Иртыше»: экспонат → подпись и источник → «в каталоге». Летопись: хронология и подборка, пояснение редакции отдельно от фактов.

## 6. Админка (2 мин) — сценарии 6, 7
Редактор: новая запись → копия → «Отправить на проверку». Модератор: уведомление → «Вернуть» с комментарием → редактор правит → одобрить → опубликовать. Запись появилась в поиске сайта. Журнал действий.
Вход `ridder`: видит только свой филиал, публикует новость филиала.
Импорт: файл-образец → сопоставление → ошибки по строкам → импорт черновиками → откат.

## 7. Негативные случаи (30 с) — сценарий 9
Закрытая запись не находится; закрытая копия — описание есть, файла нет. Прямая ссылка на закрытый файл — 404.

## Вопросы жюри — короткие ответы

| Вопрос | Ответ |
|---|---|
| Где будут данные? | Код готов к серверу в РК: `docker compose` (PostgreSQL + сайт). Vercel и Supabase — только для демо. |
| Что уходит в ИИ? | Вопрос без ИИН, телефонов и почты и описания открытых записей. Закрытые вопросы до модели не доходят. Вопросы не сохраняются. Модель меняется настройкой. |
| ИИ выдумает шифр? | Шифр в ответе сверяется с найденными записями; неподтверждённый помечается. Источники — только из каталога. |
| ИИ недоступен? | Ответ по шаблону из поиска; остальной сайт не зависит от модели. |
| Как выдержит 50 тысяч записей? | Полнотекстовые индексы PostgreSQL (GIN) и pg_trgm; отдельный поисковый сервер на таком объёме не нужен. |
| Кто что может в админке? | 7 ролей, права проверяются на сервере в каждом действии; филиал — только свои материалы. |
| Как попасть закрытому в открытый доступ? | Никак без двух шагов: снять закрытие у описания и у файла; в поисковый индекс закрытое не попадает. |
| Лицензии? | Только свободные: MIT, Apache-2.0, ISC, BSD; libvips — LGPL, подключается динамически. Таблица — в ARCHITECTURE.md. |
| Что не доделано? | Документы демо; лимит файла 4 МБ на стенде; координаты приблизительные; переводы частично машинные. |
