# Инструкция для сотрудников архива

Админка: **/admin**. Вход по логину и паролю. После 5 ошибок вход блокируется на 15 минут; после 30 минут бездействия нужно войти снова.
В меню видны только разделы, разрешённые вашей роли.

## Роли

| Роль | Что может |
|---|---|
| Главный администратор | всё, включая журнал действий и пользователей |
| Администратор сайта | страницы, новости, пользователи, журнал |
| Редактор | создаёт и правит материалы, проверяет и публикует |
| Сотрудник архива | каталог, файлы, импорт и выгрузка, подборки и выставки (без публикации) |
| Администратор филиала | сведения и новости только своего филиала |
| Модератор | проверяет и публикует |
| Аналитик | сводка и статистика |

## Как материал попадает на сайт

Черновик → **Отправить на проверку** → проверяющий: **Вернуть на доработку** (с комментарием) или **Одобрить** → **Опубликовать**.
Проверяющие получают уведомление на странице «Сводка», автор — уведомление о доработке. В истории видно, кто и когда менял статус.
Если правку опубликованного материала делает сотрудник без права публикации, материал снимается с сайта до повторной проверки.

## Электронный каталог

- **Новая запись**: «Электронный каталог» → «+ Новая запись». Обязательны название, архивный шифр, дата (как в документе) и год.
- **Доступ к описанию**: «Публично», «Не публиковать», «Требует проверки». Опубликовать можно только запись с доступом «Публично».
- **Цифровые копии**: в карточке записи — «Добавить файлы» (JPEG, PNG, WebP, TIFF, PDF; на демо-стенде до 4 МБ). Новый файл закрыт;
  чтобы показать его на сайте, выберите «Публично» и «Применить». Для изображений сайт сам делает облегчённую копию.
- **Импорт из Excel/CSV**: «Импорт и выгрузка» → фонд → файл (первая строка — заголовки; образец — на той же странице) →
  проверьте сопоставление колонок → посмотрите ошибки по строкам → «Импортировать». Записи создаются черновиками.
  Если импорт оказался ошибочным — «Откатить импорт»: удалятся записи, которые ещё никто не менял.
- **Выгрузка**: «Выгрузить открытые описания (CSV)» — только опубликованные записи с открытым описанием.

## Подборки «Летописи» и онлайн-выставки

«Подборки и выставки» → «+ Новая подборка» / «+ Новая выставка» → добавляйте материалы по шифру или названию.
Добавить можно только опубликованные записи каталога с открытым описанием; источник подставится сам.
В подборку можно добавить событие хронологии. У экспоната выставки отметьте «Право на публикацию проверено» — без этого выставку не одобрить.
Пояснение редакции пишется в отдельном поле и показывается отдельно от фактов с источниками.

## Новости и страницы

- **Новости**: заголовок, кратко, текст, рубрика, филиал → согласование как у остальных материалов.
- **Страницы раздела «Об архиве»**: «Страницы» → правка текста; прежняя версия сохраняется в истории.

Разметка текста: абзацы — через пустую строку; подзаголовок — строка с `## `; пункт списка — с `- `; **жирный** — `**текст**`;
ссылка — `[текст](адрес)`.

## Филиалы

«Филиалы» → «Изменить»: адрес, телефон, почта, режим работы, показ на карте. Администратор филиала видит кнопку только у своего филиала.
