# Внешние интеграции

По доп. ТЗ 3.6: владелец, способ доступа, передаваемые данные, ключи, ограничения, резервный сценарий, статус.

| Интеграция | Владелец | Доступ | Что передаётся | Ключи | Ограничения | Резервный сценарий | Статус |
|---|---|---|---|---|---|---|---|
| Языковая модель для помощника «Ахмет» | OpenRouter (по умолчанию модель DeepSeek V4.1 Flash) или Anthropic — выбирается настройкой | HTTPS API с сервера сайта | Текст вопроса после удаления ИИН, телефонов и почты; найденные открытые записи каталога (название, дата, место, шифр). Закрытые записи, файлы и данные посетителей не передаются. В OpenRouter включён запрет поставщикам хранить данные для обучения (`data_collection: deny`) | `OPENROUTER_API_KEY` или `ANTHROPIC_API_KEY` в переменных окружения | Платно за объём; лимиты `AI_DAILY_LIMIT` и `AI_PER_IP_PER_10MIN`; общий пул OpenRouter иногда отвечает 429 | Ответ по каталогу по шаблону с пометкой «демо» | Реализовано (демо) |
| Распознавание речи (кнопка «Голосом») | Браузер посетителя (Web Speech API) | В браузере | Звук обрабатывает браузер; сайт получает только текст | Нет | Есть не во всех браузерах | Кнопка скрывается, вопрос вводится с клавиатуры | Реализовано |
| eGov.kz, e-Otinish | Государственные порталы РК | Явные внешние ссылки | Ничего | Нет | — | Телефон приёмной архива | Реализовано |
| Карта (OpenStreetMap), маршрут (2GIS / Google Maps) | OSM Foundation, 2GIS, Google | Плитки карты; ссылка на внешний маршрут | Координаты выбранного филиала; геолокация — только с разрешения посетителя и только в его браузере | Нет | — | Текстовый адрес и ссылка на внешний маршрут | Реализовано |
| Instagram, Facebook | Meta | Ссылки на аккаунты | Ничего | Нет | Ленты — только при доступном API | Ссылки | Ссылки — реализовано |
