# Готовность модулей

Статусы по доп. ТЗ, п. 5: «Реализовано», «Частично», «Имитация/макет», «Предложено для следующего этапа». Обновляется по ходу работы.

| Светлая и тёмная темы | Реализовано | По системной настройке или выбору; выбор запоминается; смена не сбрасывает страницу и запрос |
| Главная страница | Реализовано | Плитки разделов, строка поиска с вкладками, голосовой ввод, блок «Как получить справку» со ссылкой на eGov.kz, онлайн-выставки, новости, ближайшие памятные даты, филиалы |
| Схема базы | Реализовано | Все сущности ТЗ 11: пользователи, роли и права, фонды, описи, дела, документы, файлы (мастер и облегчённая копия), коллекции, личности, события, выставки, экспонаты, филиалы, новости, категории, теги, языковые версии, журнал действий; статусы согласования ТЗ 6.7 |

| Электронный каталог | Реализовано | 1667 открытых фондов из перечня архива (перенос со старого сайта; 38 секретных не публикуются) и 24 демо-документа. Поиск по словам с русской морфологией, по номеру фонда и шифру; варианты написания (Өскемен / Усть-Каменогорск / Ust-Kamenogorsk, Риддер / Лениногорск); период и вид материала понимаются из запроса («фото … 1960-х»); при опечатке — похожие по написанию. Фильтры: вид, годы, фонд, место хранения, наличие копии, личные фонды; сортировка; постраничный вывод по 20; открытый API `/api/catalog` с теми же правилами |

Три ситуации ТЗ: ответ с источником, «нет данных» без выдумок, запрос к закрытым сведениям (готовый ответ без модели + порядок запроса через eGov.kz / e-Otinish). Шифры, которых нет среди найденного, заменяются на «[шифр не подтверждён]». ИИН, телефоны, почта вырезаются до обработки; вопросы не сохраняются. Каждый ответ помечен «сформировано автоматически». Без ключа / при сбое / при исчерпании лимита — ответ по каталогу по шаблону с открытой пометкой «демо». Голосовой ввод, три языка |

Маршрут — в 2GIS и Google Картах по текстовому адресу. Если карта не загрузилась — сообщение, список и маршруты работают. Метки приблизительные (центр населённого пункта) и так подписаны |

## Известные ограничения

- Помощник на демо-стенде обращается к внешней модели через OpenRouter (см. [INTEGRATIONS.md](INTEGRATIONS.md)). Для боевой работы — модель на инфраструктуре в РК или по договору с поставщиком; меняется настройкой `AKHMET_PROVIDER` / `AKHMET_MODEL` без правки кода.
- Координаты филиалов на карте приблизительные (центр населённого пункта), проставлены разработчиком; архиву нужно подтвердить точные — в базе для этого есть отметка `coords_verified`. Режим работы филиалов, кроме главного здания, в материалах не указан.
- Лимиты обращений к модели считаются в памяти процесса и сбрасываются при перезапуске.

- Прототип, а не введённая в эксплуатацию информационная система (доп. ТЗ 4).
- Для боевой работы персональные данные и запросы к ИИ должны обрабатываться на инфраструктуре в Республике Казахстан; демо-стенд размещён на облачных сервисах только для показа.
- Часы работы на прежнем сайте (9:00–18:00) и в материалах заказчика (8:00–17:00) расходятся; на сайте указаны материалы заказчика, требуется подтверждение.
- У двух филиалов (Глубокое, Зайсан) адрес почты в исходной таблице, вероятно, с опечаткой — не показан до уточнения.
- Перечень фондов — по состоянию на 2018 год (последняя версия, опубликованная на прежнем сайте). Перечень на 01.01.2026 и перечень личных фондов архив предоставит отдельно; формат загрузки тот же (`scripts/convert/funds_from_xlsb.py`).
- Документы ниже уровня фонда — демонстрационные: записи и шифры условные, лежат в отдельных фондах «ДЕМО-1…3», изображения сгенерированы и помечены «ДЕМО». Демо-страницы закрыты от индексации.
- Демо-копии — сгенерированные SVG. Загружаемые файлы проверяются по сигнатуре формата и размеру; проверка антивирусом (например, ClamAV) — для боевой версии.
- Файлы на стенде хранятся на диске сервера; для облака — S3-совместимое хранилище (Supabase Storage), меняется в `src/lib/storage.ts`.
